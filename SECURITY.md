# Politique de sécurité - QuartierAlert

## Signalement d'une vulnérabilité
Si vous découvrez une vulnérabilité de sécurité, **ne la publiez pas publiquement**.

Merci de signaler de manière privée en décrivant :
- Description de la vulnérabilité
- Étapes pour la reproduire
- Impact potentiel
- Proposition de correctif si possible

**Contact sécurité :** À définir par l'équipe (aucune adresse n'est actuellement renseignée).

## Bonnes pratiques
- Clés API uniquement côté serveur (Gemini, Supabase service role)
- Valider toutes les entrées utilisateur
- Protéger les routes sensibles
- Ne pas logger de données sensibles
- Gérer prudemment la localisation (respect de la vie privée)
- Modération des signalements
- Vérification humaine obligatoire pour les propositions IA
